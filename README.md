# AAIF data archive

Archive copy of the data of the Open Access Database "Adjective-Adverb Interfaces in Romance" (AAIF), an annotated corpus of Romance adjectives in adverbial function, derived adverbs and adverbial prepositional phrases with an adjectival core, in French, Southern Italian varieties, Latin, Brazilian Portuguese, Old Romanian and Spanish. The database is published by the Department of Romance Studies and the Centre for Information Modelling (ZIM) of the University of Graz at https://gams.uni-graz.at/aaif (handle `hdl:11471/513.30`). This repository keeps its TEI, RDF, ontology, schema and documentation byte for byte as GAMS delivered them, with checksums, and documents what the data contains and where TEI, RDF and ontology disagree.

## Contents

| Path | Content |
|---|---|
| `data/tei/` | TEI of the nine corpora and their bibliographies, the ODD and the TEI description of the annotation model |
| `data/rdf/` | RDF of every corpus and bibliography, generated by GAMS, and the OWL ontology |
| `data/schema/` | RelaxNG schema generated from the ODD |
| `data/docs/` | Manual of the Word annotation tool and the description of the annotation model, as PDF |
| `data/manifest.json` | Every archived file with PID, datastream, source URL, size, SHA-256 and retrieval date |
| `data/objects.json` | Inventory of every GAMS object of the database |
| `knowledge/` | Documentation of data, annotation model, decisions and checks, starting at [knowledge/INDEX.md](knowledge/INDEX.md) |
| `01_fetch.py`, `02_analyze.py`, `03_verify.py` | Retrieval, analysis and checksum verification |

File names follow the pattern `<PID>.<datastream id>.<extension>` with `:` in the PID replaced by `-`.

## Reading the data

[knowledge/data.md](knowledge/data.md) describes the corpora, the TEI and RDF structure and the known properties of the data. [knowledge/annotation-model.md](knowledge/annotation-model.md) explains the linguistic categories, decodes the compact annotation codes in `w/@function` and aligns the names used in the RDF with those of the ontology. Anyone reusing the RDF or the ontology should read both first, because they differ in several places.

## Usage

The scripts need [uv](https://docs.astral.sh/uv/).

```
uv run 03_verify.py           # check every file against the manifest, offline
uv run 02_analyze.py          # analyse TEI, RDF and ontology, report in reports/analysis.json
uv run 01_fetch.py            # fetch missing datastreams from GAMS, --force fetches everything again
```
